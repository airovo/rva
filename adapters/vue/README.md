# @airovo/rva-vue

Vue 3 wrapper for the `<rva-image>` web component.

```bash
npm i @airovo/rva-vue
```

```vue
<script setup>
import { RVAImage } from "@airovo/rva-vue";
</script>

<template>
  <RVAImage src="/hero.rva" alt="Hero" />
</template>
```

Peer dependency: `vue >= 3.3`.
